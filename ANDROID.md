# Сборка под Android (Capacitor)

Проект спроектирован под обёртку **Capacitor**. Ниже — шаги для получения APK.
Это отдельный этап: сначала убедитесь, что MVP работает в браузере (`npm run dev`).

## Предварительные требования

- Node.js 18+
- [Android Studio](https://developer.android.com/studio) с Android SDK
- JDK 17
- Переменные окружения: `ANDROID_HOME` (или `ANDROID_SDK_ROOT`) указывает на SDK

## Шаги

```bash
# 1. Установить Capacitor (если ещё не установлен)
npm install @capacitor/core @capacitor/cli
npm install -D @capacitor/android

# 2. Создать конфиг Capacitor (id приложения задайте свой)
npx cap init SelfCRM com.example.selfcrm --web-dir=dist

# 3. Добавить платформу Android
npx cap add android

# 4. Собрать веб-приложение
npm run build

# 5. Синхронизировать сборку с Android-проектом
npx cap sync android

# 6. Открыть в Android Studio и собрать APK
npx cap open android
```

В Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
Готовый APK появится в `android/app/build/outputs/apk/debug/`.

## Замечания по хранению

- Приложение использует локальное хранилище браузера, которое в Capacitor WebView
  **сохраняется между запусками** (для `android` — через штатный WebView с persistent storage).
- Если потребуется нативный SQLite, замените реализацию `KVStore` в `src/db/kvstore.ts`
  на `@capacitor-community/sqlite`, реализовав тот же интерфейс. Интерфейс приложения не изменится.

## Офлайн и относительные пути

- В `vite.config.ts` задан `base: './'`, чтобы ассеты корректно загружались из `file://`.
- Роутинг на hash-фрагментах — безопасен для WebView.

## Маршрут и навигация

Кнопка «Маршрут» в карточке клиента открывает `geo:`-URI через `window.open(uri, '_system')`.
Capacitor передаёт такую ссылку операционной системе, и Android показывает системный выбор
приложения для навигации (Google Maps, Яндекс.Карты, 2ГИС и т.д.). Дополнительных
Capacitor-плагинов для этого не требуется.

Кнопка «Вызов» (и сам номер телефона) в карточке клиента открывает `tel:`-URI тем же
способом — `window.open(uri, '_system')`. Android передаёт ссылку в звонилку, поэтому
отдельный плагин звонков не нужен. В браузере используется обычный `tel:` на текущей странице.

## PDF-чек

Чек генерируется офлайн на устройстве (библиотека pdfmake, шрифт Roboto с кириллицей).
Модуль загружается лениво, поэтому pdfmake не увеличивает основной бандл приложения.
На Android PDF записывается во временный каталог устройства (`@capacitor/filesystem`)
и открывается системное меню «Поделиться» (`@capacitor/share`) — так файл можно отправить
в мессенджер, почту или сохранить. В браузере файл скачивается обычным способом.

## Ориентация экрана

Приложение зафиксировано в портретной ориентации (`android:screenOrientation="portrait"`
в `AndroidManifest.xml`) — горизонтальный режим отключён.

## Проверка обновлений

Кнопка «Настройки → Обновления → Проверить» запрашивает последний релиз из GitHub-репозитория
(`doc9830/SelfCRM`) и сравнивает его версию с текущей. Если доступна новая версия, приложение
предлагает скачать APK со страницы релиза (открывается в системном браузере).
