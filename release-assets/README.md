# release-assets

Каталог обложек для постов в Telegram: для релиза с тегом `v1.4.0` положите картинку в
`release-assets/v1.4.0/`:

```text
release-assets/
└── v1.4.0/
    ├── cover.png          ← уходит в Telegram как обложка поста
    ├── screenshot-1.png   ← используется, если cover.* нет
    └── screenshot-2.png
```

Правила:

* имя тега — точно как у релиза (`v1.4.0`, с префиксом `v`);
* приоритет файлов: `cover.*` → `screenshot-1.*` → `screenshot*`;
* форматы: `png`, `jpg`/`jpeg`, `webp`; размер — чем меньше, тем лучше (до ~5 МБ);
* каталог можно не создавать: без него пост выходит без обложки, а причина попадает в лог
  workflow.

Альтернатива без коммитов: приложить картинку `cover.png` прямо к GitHub Release — ассет
релиза имеет приоритет над файлами в этом каталоге.

Подробности — в [docs/TELEGRAM_RELEASES.md](../docs/TELEGRAM_RELEASES.md).
