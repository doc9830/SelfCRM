# SelfCRM

**SelfCRM** — простая мобильная CRM для одного человека: частного мастера, небольшой
бригады или микробизнеса. Все данные хранятся на вашем устройстве, интернет для работы
не обязателен.

https://doc9830.github.io/SelfCRMlanding/

## Возможности

- **Клиенты** — карточка с контактами, адресом и историей заказов.
- **Главный экран** — плашки «Активные заказы» (по нажатию открывается список новых и «в работе») и «Выручка» (по нажатию — статистика за текущий месяц).
- **Заказы** — статусы «Новый / В работе / Завершён / Отменён», фильтр «Активные», список позиций и итоговая сумма.
- **Чек в PDF** — формируется для завершённого заказа и отправляется через системное меню «Поделиться».
- **Товары и склад** — каталог с ценами и остатками; остатки списываются автоматически при заказах.
- **Услуги** — позиция «Услуга» не учитывается на складе и всегда доступна при оформлении заказа.
- **Сортировка** — значок со стрелочками в шапке со списком вариантов: заказы по дате, статусу и сумме; товары по алфавиту, остатку и цене.
- **Статистика за период** — выручка, число заказов, средний чек, статусы, топы товаров, услуг и клиентов за день, неделю, месяц, квартал, год или произвольный диапазон дат.
- **Маршрут** — кнопка «Маршрут» открывает навигатор (Google Maps, Яндекс.Карты и др.) до клиента.
- **Адреса** — автодополнение при вводе (сервис Дадата + локальная база адресов).
- **Резервные копии** — экспорт и импорт всех данных в JSON-файл.
- **Тёмная тема** — комфортная работа при слабом освещении.
- **Обновления** — версия проверяется автоматически при запуске, а новая версия предлагается в настройках.

## Установка на Android

1. Скачайте актуальный APK со страницы [релизов](https://github.com/doc9830/SelfCRM/releases).
2. Откройте скачанный файл и разрешите установку из неизвестных источников, если система попросит.
3. Откройте SelfCRM и работайте.

> Приложение работает полностью офлайн. Интернет нужен только для подсказок адресов,
> построения маршрута и проверки обновлений.

## Все функции — из коробки

Все возможности SelfCRM доступны сразу и без ограничений: клиенты, заказы, товары, услуги и склад,
статистика за период, сортировка списков, чек в PDF, маршрут, адреса и резервные копии.
Никаких платных тарифов и переключателей.

## Ваши данные

Все данные — клиенты, заказы, товары и настройки — хранятся **локально на устройстве**
и не отправляются на сервер. Вы можете выгрузить резервную копию в
**Настройки → Резервная копия → Экспорт** и перенести её на другое устройство через импорт.

### Как приложение защищает данные

- Облачный бэкап Android отключён (`allowBackup=false`): данные не уходят в аккаунт Google
  и не переносятся через `adb backup`. Копии делаете вы сами — экспортом в файл.
- Перед импортом резервной копии и перед сбросом данных приложение сохраняет копию текущего
  состояния. Её можно скачать в **Настройки → Резервная копия → Данные до импорта**.
- Если файл данных на устройстве окажется повреждён, приложение не затрёт его: исходное
  содержимое сохраняется, а в настройках появляется предупреждение с кнопкой
  «Скачать повреждённые данные».
- Обновления проверяются по подписи: APK, подписанный другим ключом, установить не получится.

## Проверка обновлений

Версия проверяется автоматически при каждом запуске приложения. Если на GitHub есть более
новая версия, снизу появляется полупрозрачное уведомление «Доступна версия …»: нажатие
открывает **Настройки → Обновления** с уже готовым списком изменений, а крестик скрывает
уведомление до следующей версии.

Проверить обновление вручную можно в **Настройки → Обновления → Проверить**. Если доступна
новая версия, приложение покажет список изменений и предложит скачать обновление.

## Адреса и маршрут

- Поле «Адрес» в карточке клиента предлагает подсказки по мере ввода. Источник — сервис
  [Дадата](https://dadata.ru); если он недоступен, используется локальная база адресов.
- Кнопка «Маршрут» открывает навигатор до клиента.

## Разработчикам

```bash
npm install
npm run dev        # запуск в браузере
npm run build      # production-сборка в dist/
npm test           # тесты
npm run typecheck  # проверка типов
npm run bump -- 1.0.9  # поднять версию сразу в package.json, src/version.ts и build.gradle
```

Ключ подсказок адресов (Дадата) в исходниках не хранится: положите `VITE_DADATA_TOKEN=...`
в файл `.env.local` перед `npm run build`, иначе подсказки работают только по локальной базе.
Подробности — в [ARCHITECTURE.md](./ARCHITECTURE.md).

Сборка APK под Android описана в [ANDROID.md](./ANDROID.md), архитектура — в
[ARCHITECTURE.md](./ARCHITECTURE.md).
